# ofxGgmlDiffusion v1.0.1

## Compatibility

- openFrameworks: `of_v20260406_vs_64_release`
- minimum `ofxGgmlCore`: `1.0.1` / commit `2171e8b`
- `OFXGGML_DIFFUSION_VERSION_STRING`: `1.0.1`

## Highlights

- Added independent Diffusion addon version metadata.
- Exposed version metadata through `ofxGgmlDiffusion.h`.
- Documented the release checklist and release policy for diffusion and GAN
  workflows.
- Kept generated stable-diffusion.cpp runtime files and model assets out of git.
- Preserved GAN image generation as an image-generation lane in this addon.

## Runtime Scope

This release includes typed diffusion request/result/config helpers, text-to-image
bridge boundaries, native stable-diffusion.cpp setup scripts, async runner,
PhotoMaker request data, GAN request types, tiny GAN preset helpers, fixture
generation, deterministic tiny GAN proof paths, and dry-run tiny GAN training
contracts.

It does not claim complete Stable Diffusion, SDXL, Flux, PhotoMaker, inpainting,
image-to-image, or full adversarial training support yet. Those remain explicit
runtime and roadmap tasks.
